### TFLite输出映射（关键突破）

```
输出索引含义:
[0] -> dia_d2 (舒张压第2位)
[1] -> sys_d2 (收缩压第2位)
[2] -> pulse_d1 (脉搏第1位)
[3] -> dia_d1 (舒张压第1位)
[4] -> sys_d1 (收缩压第1位)
[5] -> sys_d3 (收缩压第3位)
[6] -> pulse_d2 (脉搏第2位)

正确解码:
systolic = outputs[4]*100 + outputs[1]*10 + outputs[5]
diastolic = outputs[3]*10 + outputs[0]
pulse = outputs[2]*10 + outputs[6]
```

### 关键技术决策

1. **分类优于回归**：预测数字位(0-9)比预测数值更容易收敛
2. **多头架构**：每个数字位独立预测，避免数值整体预测困难
3. **暴力搜索映射**：TFLite输出顺序被打乱，通过测试找到正确排列
4. **最高优先级集成**：置信度>0.8直接返回，跳过传统OCR方法

### 待解决问题

1. **三位数舒张压**：当前模型只训练2位，需增加100+范围样本
2. **TFLite Flutter配置**：需手动下载平台C库文件
